# 按规则归档文件，保留路径对照

## 工作痛点与目标

**工作痛点：** 混合文件堆在同一目录，分类容易误移或覆盖。

**解决后得到：** 交付归档副本、文件清单和可追溯的路径对照表。

下载资料、合同、图片与表格混在一起，需要按格式整理，又想知道每个文件原来在哪里。先列清单、在副本上整理，再核对数量，适合第一次批量归档。

## 开始前准备什么

- 建立练习工作空间，把待整理资料复制到「待整理资料」；原件另行保留。
- 按实际归档范围准备文件副本；若需要按格式分类，先选 PDF、Word、表格、图片、压缩包各一份核对规则。
- 约定只处理目录第一层文件，不递归改动已有项目文件夹；输出放在「输出/归档副本」。

## 分步解决问题

### 1. 把材料、规则和交付写清楚

新建任务并选定练习空间，使用「计划」模式。把下面的目录名改为实际目录名后发送。分类按后缀进行，PDF 被放入「合同与文书」不意味着它已被识别为合同。

![派活单三要素示意：材料范围、处理规则、交付路径](/solve/20261018/03-01.png)

*流程示意：先明确范围和规则，再指定交付。*

```text
请只读取当前工作空间下「待整理资料」第一层文件，先生成整理计划，不移动、覆盖或删除原件。
分类规则：PDF→01_合同与文书，Word→02_工作文稿，Excel/CSV→03_报表与数据，
图片→04_扫描凭证，压缩包→05_安装与归档包。未知格式标为待确认。
先列出文件总数、每类数量及前20个文件的原完整路径、拟输出完整路径、冲突情况。
已有子文件夹不处理。同名文件使用日期加递增序号，仍冲突则停止该项。
等我核对计划后，只把确认的文件复制到「输出/归档副本」，不要移动原件。
```

![PDF、Word、表格、图片、压缩包与目标分类目录的对应示意](/solve/20261018/03-03.png)

*规则示意：在归档副本中应用分类，原始目录保持原样。*

如客户端出现「增强提示词」按钮，可用它检查遗漏，但发送前仍需逐句核对，避免自动补入移动、删除或扩大目录范围的要求。

![WorkBuddy文件整理提示词输入区与增强提示词按钮](/solve/20261018/03-02.jpg)

*参考界面：箭头标出增强提示词入口，按钮位置以当前客户端为准。*

### 2. 审核预览后执行副本整理

核对全部分类规则和冲突项，再检查预览中的路径是否都位于指定输出目录。已有同名目标不能覆盖。确认后补充：

```text
计划已核对。按确认范围复制归档，不扩大读取范围。
生成「输出/归档对照表.csv」，包含原完整路径、新完整路径、文件大小、处理状态和异常原因。
跳过未确认项并单列说明；结束时列出成功、跳过、失败数量。
```

![文件归档先预览、核对目标路径、确认后执行的流程示意](/solve/20261018/03-04.png)

*流程示意：确认范围后再执行。*

### 3. 需要回退时先检查对照表

本方案保留了原件，通常无需把文件移回。若后续另行批准过真实移动，应以原完整路径、新完整路径和当前状态生成回退预览，核对重名与路径占用后再人工确认；遇到碰撞不覆盖。对照表不能保证所有状态都可自动恢复。

## 检查交付结果

- 对照源清单核验：成功数＋跳过数＋失败数应等于本次处理文件数；子目录不能被计入已处理文件。
- 抽查各类副本能否打开，大小是否一致；有条件时用哈希核验副本内容。
- 原件应仍在原路径；未知格式、重名、无法读取的文件保留明确原因，不能默默丢弃。
- 将后续真实移动、覆盖或删除作为独立操作，先看影响清单再由本人确认。
