# 把销售表做成可核对的网页看板

## 工作痛点与目标

**工作痛点：** 销售明细难以直接汇报，图表和指标又容易口径不一致。

**解决后得到：** 交付可本地打开的HTML看板、指标口径表与数据核对说明。

销售明细需要变成可查看趋势、区域对比和品类构成的页面。先解决指标怎么算、数据缺什么，再制作网页；视觉效果不能替代核对。

## 开始前准备什么

- 准备获准使用的真实销售数据副本；多份表先完成字段对齐与合并，保留原始文件用于核对。
- 至少检查订单标识、日期、金额及区域/品类字段。若没有成本、目标或完整订单号，不输出虚构的毛利、达成率或客单价。
- 约定退款、取消订单、跨币种和重复明细的处理；单笔订单多行明细时订单量按已确认唯一键统计。

## 分步解决问题

### 1. 先列指标与页面草图

使用「计划」模式检查数据并说明能回答的问题。

```text
只读已确认的销售明细，列出字段、时间范围、行数、缺失值与重复情况。
先给指标口径表：销售总额、去重订单数、客单价、毛利或毛利率。
逐项列所需字段、公式、过滤条件、币种/单位和是否可计算；缺字段标「无法计算」。
给出月度趋势、区域对比、品类构成、城市排名的布局计划。
没有对应字段则删除该图，并说明原因；不要生成演示数据填空。
等待我确认口径与布局。
```

![趋势用折线、对比用柱状、构成用环形、明细用排名表的示意](/solve/20261018/08-02.png)

*图表选型示意：品类过多时可改排名条形图，按真实问题选择。*
![WorkBuddy销售分析任务指令及处理计划清单](/solve/20261018/08-03.png)

*参考规划界面，只说明分析计划的组织方式，不是HTML看板成品。*

### 2. 生成HTML和独立的核对表

确认口径后，让工具读取实际数据生成。数据量较大时，图表使用经过核对的聚合结果，页面说明聚合范围和截止时间。

```text
按确认口径生成「输出/销售业绩看板.html」，包含可计算的指标卡、趋势、区域、品类和排名。
页面标清来源、数据期间、过滤条件、币种单位、更新时间及缺失项。
支持鼠标查看图表数值，并为核心图提供可读的数据表。
所有样式、脚本及图表依赖打包在本地单文件，不从CDN、在线字体或远程接口加载。
若不能满足单文件离线条件，先说明依赖，不声称离线可用。
另存「指标核对表.csv」与「口径说明.md」，列出聚合值和来源，不改源表。
```

### 3. 断网打开，再检查交互和窄屏

用浏览器打开输出HTML，断网刷新，确认数字和图表仍显示。鼠标悬停核对数值，测试图例和筛选，并检查筛选后所有卡片与图表是否使用一致范围。缩窄窗口看有无溢出、数字遮挡。

![电商销售分析报告图表拼图，包含趋势、排名、热图、散点和解释](/solve/20261018/08-04.png)

*参考分析报告，放在核对环节参考；静态图不能证明网页悬停、离线或移动端已测试。*

## 检查交付结果

- 看板总额、分组总额与独立核对表一致；订单数、客单价按同一已确认口径计算。
- 抽取月份、区域和品类回查明细；排序、Top10、其他项及缺失项应有说明。
- 页面不出现输入中没有的成本、目标或利润；空数据、零分母显示明确状态。
- 实际完成断网、悬停、筛选和窄屏检查后再描述能力；对外分享前确认页面内嵌数据可公开。
