# 用三个助手衔接选题、大纲与审校

## 工作痛点与目标

**工作痛点：** 一个人反复切换选题、写作和排版，材料交接不清导致返工。

**解决后得到：** 交付可交接的选题卡、大纲、人工正文与审校清单。

有专业素材和写作意图，但选题、大纲、正文、排版审校混在同一轮对话中，容易跳步或改乱版本。把职责拆为三个角色，用明确文件交接，适合个人内容生产。

## 开始前准备什么

- 自行准备有权引用的参考文章、读者问题、写作目标、目标读者、素材来源和自己的实际经验。
- 准备写作规范与配图清单；没有规范时先明确用词、标点、引用和禁用表达，不把他人个人风格直接当自己的经历。
- 设置「素材」「选题」「大纲」「正文」「审校」「输出」目录。各助手使用不同输出文件，确认交接版本，避免同时覆盖同一正文。

*分工示意：这条流程有前后输入依赖，需要交接和人工确认。*

## 分步解决问题

### 1. 选题情报员先整理证据与读者问题

在独立任务中给选题角色限定职责，用「仅问答」先分析，再按需要另存选题卡。

```text
根据我提供的参考文章和读者问题，整理候选选题，不写正文。
每个选题列：目标读者、具体困境、可回答的问题、可用证据及来源、资料缺口。
真实读者反馈与推测的读者情绪分开；参考文章未给留言时不要虚构留言或热度。
给出3个可选角度，注明哪些需要我的真实经验，哪些已有材料支持。
由我选定一个选题后，整理成「选题/选题卡-v1.md」，不抄写参考文章段落。
```

![选题情报员读取参考内容和问题、提炼痛点且不写正文的职责示意](/solve/20261018/13-02.png)

*职责示意：先做选题卡，交给本人确认。*

### 2. 结构大纲师使用已确认选题卡

把确认的选题卡和素材清单交给第二个任务。大纲不要求必须设计下一篇悬念，单篇应能独立解决问题。

```text
读取我确认的「选题/选题卡-v1.md」及对应素材，制作独立可读的教程大纲。
结构为：读者现场问题、准备条件、具体操作与示例、结果核对和边界。
每节列核心观点、所需事实、来源、拟放截图及待补材料，不为凑结构编造案例。
无法支持的观点标待补或删去，不写正文，不添加关注口令或下期钩子。
输出「大纲/文章大纲-v1.md」，等我确认后再进入正文。
```

![现场困境、破局准备、操作指令、安全边界的四段式示意](/solve/20261018/13-04.png)

*结构示意：按独立网站文章用途调整，图中进阶内容不要求下期承接。*

本人根据确认大纲写正文，补入确实发生过的经验、已核验参数与截图。允许助手辅助表达，但没有实际经历就不写「我亲测」「已经跑通」或虚构成功案例。确认正文版本后再交审校。

### 3. 排版风控员只审指定版本

```text
读取「正文/文章-v1.md」、写作规范和配图清单，只处理这个版本。
输出审校清单：事实与引用、夸张或绝对保证、个人/敏感信息、错别字和标点、段落、图片路径及图文是否匹配。
每项写位置、问题、建议和需人工判断之处；无法核实的事实不能直接改成肯定句。
不要补造来源或截图。先输出「审校/审校清单-v1.md」，我确认修改后再另存修订稿。
排版转换保留标题、列表、引用、图片说明与链接，不上传、不发布、不发送。
```

![禁用词、标点规范、段落和图片路径的审校清单示意](/solve/20261018/13-05.png)

*审校示意：机械检查与事实判断均保留可复核记录。*

## 检查交付结果

- 选题卡、大纲、正文和审校清单版本一致，每个角色都读到了上一步已确认产物。
- 文章独立可读，事实和截图有来源，推断与个人经验不被冒充为实测。
- 审校修改没有悄悄新增事实、删掉条件或改变数据；图片画面与对应操作一致。
- 三个角色的交接完成后由本人审定最终稿，发布是独立动作；相互依赖的工序不能宣称无需交接即可全自动并行。
