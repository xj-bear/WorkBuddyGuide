# 对齐字段后合并多月报表

## 工作痛点与目标

**工作痛点：** 多月报表列名、日期和金额口径不同，直接追加会错列。

**解决后得到：** 交付标准总表、字段映射和能解释行数金额差异的日志。

不同月份、部门或区域的报表需要合成一张长表，但列名、顺序、金额含义各不相同。这里先确认业务口径，再统一字段和月份，最后对账。

## 开始前准备什么

- 将 Excel/CSV 副本放入「月度报表汇总」，记录每个文件对应月份、工作表和数据范围。
- 先选两到三个月的报表副本核对字段映射与汇总口径，确认后再处理完整月份；缺少月份时在总表中明确标记。
- 明确成交金额是否含税、含退款、币种和单位；「销售额」「实收金额」只有业务含义一致才可映射。
- 约定订单唯一键。订单编号可能跨月重复或包含多行商品，不能直接按订单号去重。

## 分步解决问题

### 1. 盘点源表并确认映射

选定工作空间，先用「计划」模式读取表头和样本行。

```text
只读「月度报表汇总」中的Excel和CSV。逐文件列出工作表、表头所在行、数据行数、
日期格式、金额字段、空值及公式情况，不把标题行和小计行计为明细。
建议标准字段：客户名称、所属品类、成交金额、订单编号、所属月份、来源文件、来源行。
输出字段映射建议；销售额/实收金额需标明原含义，未获确认的口径不自动合并。
月份优先来自已确认的完整日期；文件名推断结果列为待确认，不凭「15日」猜月份。
先给我映射和异常清单，等待确认。
```

### 2. 合并并保留数据来源

确认映射、金额口径、月份规则和重复判断后继续。

```text
按已确认映射垂直合并，保留来源文件、来源工作表、来源行及所属月份。
订单号等标识按文本保留前导零。金额按约定币种和精度处理，不把空白填成0。
缺失或不可解析字段标为待核实。先标记疑似重复；只有确认的重复明细才从总表排除，
原记录保留在异常清单中。公式无法可靠读取或重算时标明，不用空值替代。
另存「输出/销售汇总总表.xlsx」，包含总表、字段映射、异常清单三个工作表。
另写「输出/合并差异日志.md」，列出各源表纳入/排除行数和金额差异原因，不覆盖源文件。
```

### 3. 用差异日志解释变化

请工具按「输入明细行数－已确认排除行数＝输出行数」列出逐文件对账；金额差异也要对应到具体记录。不同币种分开核对，不能直接相加。

## 检查交付结果

- 每份源表都出现在盘点和日志里；每行总表能追溯到源文件与行号。
- 用来源月份分组核对行数和金额，已排除的重复、小计及无效记录分别说明。
- 抽查前导零、日期跨月、空金额、退款、币种与公式值。字段同名并不等于口径相同。
- 差额无法解释时停止交付分析，把对应记录交给业务确认，不通过改金额“对平”。
