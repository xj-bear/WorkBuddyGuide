# 按客户名单生成合同与邮件草稿

## 工作痛点与目标

**工作痛点：** 逐份替换合同客户字段时，金额、名称和邮件称呼容易混用。

**解决后得到：** 交付每客户独立的合同、配套邮件草稿及字段核对清单。

已有审核过的合同模板和客户名单，需要把一行客户数据准确替换到一套独立文件中。本方案只做字段填充与邮件起草；条款修改、签署、盖章与对外发送应由负责人员另行审核。

## 开始前准备什么

- 自行准备获准使用的「标准商务合同模板.docx」与客户 Excel 副本，放入「合同制作」。本场景需自行准备模板与客户名单。
- 变量用明确占位符，例如 `{{客户名称}}`、`{{法定代表人}}`、`{{合同总额}}`、`{{签署日期}}`，表头与变量一致。固定法律条款与变量分开。
- 每行增加稳定客户编号；核对名称、金额单位、币种、日期、收款信息和必填项。客户名称相同也不能覆盖同一个文件。

*占位符示意，不是可直接使用的法律合同模板。*

## 分步解决问题

### 1. 只读检查模板与数据

先用「计划」模式建立变量映射，确认模板页眉页脚、表格等位置是否有同类占位符。

```text
只读「合同制作」中的模板与客户名单，列出全部占位符及对应Excel列。
检查客户编号重复、必填字段为空、金额/日期格式不一致和没有对应列的占位符。
不修改固定条款，不推测缺失值；异常行暂不生成。
输出客户编号、拟生成文件名、变量映射和异常原因，先等我确认。
```

### 2. 先生成一套样稿

选择一条材料完整的记录生成样稿。模板复杂时，再挑含长公司名、大额金额等边界记录复核。

```text
按确认映射，只处理客户编号「请填实际编号」这一行。
生成独立Word合同和跟进邮件txt草稿，文件名带客户编号与名称，存「输出/合同样稿」。
邮件只使用该行客户信息和该份合同，称呼、金额、签署日期与合同一致。
输出该行字段核对清单，检查未替换占位符；不发邮件，不签署，不改模板。
遇到已存在文件不覆盖，报告并等待新文件名。
```

![一行客户数据逐项替换到独立合同与配套邮件的示意](/solve/20261018/07-03.png)

*流程示意：每客户单独生成与核对，客户编号贯穿文件和清单。*

打开样稿检查版式和字段，尤其注意长名称换行、金额大小写、币种、账号及表格是否溢出。确认后再按已核对规则处理剩余清单。

### 3. 扩大批量并生成核对索引

```text
样稿已由我核对。按同一映射处理已确认的其余客户，不处理异常行。
每客户输出独立合同及邮件草稿，目录为「输出/已生成合同与邮件」。
生成「生成清单.csv」：客户编号、来源行、合同路径、邮件路径、金额、日期、状态、异常原因。
扫描残留占位符、跨客户名称混入及文件名冲突。发现异常标待复核，不自行改条款。
```

![模板和名单经单份试跑、批量生成、人工复核的示意](/solve/20261018/07-05.png)

*流程示意：先核对单份样稿，再批量生成并逐份复核关键字段。*

## 检查交付结果

- 以客户编号对照输入、生成和跳过数量，每个有效客户应对应一份合同和一份邮件草稿。
- 对每份待外发文件核对客户名称、金额、日期、账号等关键变量；检查无残留占位符、无其他客户名称与价格。
- 对固定条款、违约责任及商业承诺由相应负责人复核，不能仅依赖样稿正确就认定全批正确。
- 发送前重新核对收件人和附件一一对应，任何发送或签署另行确认。
