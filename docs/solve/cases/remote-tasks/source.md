# 从手机派发受控的远程任务

## 工作痛点与目标

**工作痛点：** 人离开工位后需要查电脑文件，却难以确认任务在哪运行。

**解决后得到：** 交付明确运行设备、读取范围和人工确认边界的远程查询结果。

出差或通勤中，想从手机查找工位电脑中的指定文件，或查看一项已确认任务的结果。先用只读查询验证设备和范围，再考虑新增输出；不要用紧急需求代替对权限的检查。

## 开始前准备什么

- 准备自己的已登录客户端与手机入口，确认账号一致、电脑开机联网、客户端可连接，授权的工作空间明确。
- 仅在实际需要本机文件时选择连接本机的模式；云端任务不能据此视为能读工位文件。
- 自行准备允许回传到手机的非敏感练习文件，放入已选工作空间。不把整个磁盘、客户合同或账号凭据作为第一次远程测试材料。

## 分步解决问题

### 1. 确认手机入口和运行模式

打开当前版本支持的小程序/IM入口，按设备连接提示选择自己的电脑。若界面提供扫码绑定，核对电脑与账号后扫码；实际绑定步骤以当前客户端为准。

### 2. 先派一个小范围只读任务

手机端发出下面的查询，把路径和文件名替换为已经在电脑上核对过的练习材料。

```text
请先确认本任务运行在我连接的哪台设备、哪个工作空间。
只读已授权空间下「远程练习」目录，列出其中第一层文件名、大小和修改时间。
再读取「练习说明.txt」，返回其中标题和第一段，并标明来源文件。
不扩大目录、不新建文件、不修改、不移动、不删除，不调用外部系统。
若不能连接电脑或读取该目录，明确报告原因，不用其他来源代替。
```

手机结果应能与电脑端文件一一对应。运行设备或目录不明确时，先停止，回到客户端核对连接状态；不能因为收到回答就认为它访问了指定本机。

### 3. 按已验证能力逐步增加任务

只读流程稳定后，可以把已审核过的合表或清单任务限定为「只在输出目录新建文件」，先展示完整计划及影响范围，再由本人确认。涉及写入、覆盖、删除或外部调用时，主动安排可执行的人工审核点。

客户端若显示授权请求，逐项检查动作与路径；若手机端没有清楚显示影响或无法处理审批，回到电脑处理。不要假设所有关键操作都一定能在手机逐次审批，也不要通过扩大权限来绕过不明请求。

## 检查交付结果

- 设备、模式、空间、目录和读取文件均与预期一致；失败或离线明确报告。
- 手机摘要能回查电脑文件，不能拿泛化回答代替实际读取结果。
- 输出路径位于确认范围，未覆盖已有文件；关键操作的人工审核方式清楚可用。
- 正式交付前本人检查内容与接收范围；批量删除、账号权限调整等任务不作为本页远程演练。
